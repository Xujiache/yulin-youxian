# 禹邻优鲜小票打印代理

版本：1.2.1

## 安全要求

- 生产 API 地址必须是 `https://你的正式域名/api`。程序会直接拒绝生产 HTTP。
- HTTP 仅用于本机开发，且只允许 `http://localhost:8080/api`、`127.0.0.1` 或 IPv6 回环地址。
- 打印密钥使用 Windows DPAPI 按“当前 Windows 用户”加密后写入 `agent.config.json`，文件中不再保存明文。
- 必须用配置时的同一个 Windows 用户运行和安装开机自启；换用户后应重新执行配置。
- 不要把 `agent.config.json`、日志、截图中的密钥或门店令牌发给他人。

## 首次安装

1. 解压到固定目录，例如 `C:\禹邻优鲜\打印代理`，之后不要移动。
2. 打开 PowerShell，在目录中执行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify-checksums.ps1
   ```

   只有显示“SHA256 verification passed”才继续。校验失败时重新下载，不要运行。
3. 双击 `setup-agent.cmd`。
4. 填写 HTTPS API 地址和管理后台生成的打印代理密钥。
5. 按向导完成打印机测试和后端连通测试。
6. 双击 `install-autostart.cmd`。任务计划程序会使用同一 Windows 用户启动监督脚本。

## 日常运行与自动恢复

- 手动运行：双击 `run-agent.cmd`。
- 自动运行：安装开机自启后，登录 Windows 即启动。
- `supervise-agent.ps1` 会在代理异常退出后重启，重试间隔逐步增加到最多 60 秒。
- 任务计划程序也配置了失败重启，且禁止同一用户重复启动多个代理实例。
- 取消自启：双击 `uninstall-autostart.cmd`，它会先停止任务再删除。

## 配置与日志

| 文件 | 用途 |
| --- | --- |
| `agent.config.json` | API、打印机信息和 DPAPI 密文；仅配置用户可解密 |
| `print-agent.log` | 代理业务日志 |
| `supervisor.log` | 进程退出与重启日志 |
| `SHA256SUMS.txt` | 发布文件校验和 |
| `VERSION.txt` | 当前版本 |

两个日志都会自动轮转，最多保留当前文件和 5 个历史文件，不会无限增长。排障时可提供日志，但不要提供 `agent.config.json`。

## 常见问题

### 提示“生产 API 必须使用 HTTPS”

正式门店不能绕过此检查。先给域名配置有效 TLS 证书，再填写 `https://.../api`。不要把公网 IP 或域名改成 HTTP。

### 提示“打印密钥无法解密”

当前 Windows 用户与首次配置用户不同，或配置从另一台电脑复制而来。切回原用户，或删除本机 `agent.config.json` 后重新运行 `setup-agent.cmd`。不要尝试手工修改密文。

### 程序退出后没有恢复

检查任务计划程序中的 `YulinYouxianPrintAgent`，再查看 `supervisor.log`。确认程序目录未移动、Windows 用户未变。

### 需要更换打印机或密钥

使用原 Windows 用户重新运行 `setup-agent.cmd`。新配置会覆盖旧密文，并立即进行打印和连通测试。

## 发布人员

构建命令：

```powershell
.\print-agent\build.ps1 -OutputDirectory "$env:TEMP\YulinPrintAgent-1.2.1"
```

版本目录不可覆盖；要发布新版本时先递增源码版本，再生成新的版本目录。构建脚本会规范化旧版 C# 编译器写入的 PE 时间戳和 MVID，同一源码与编译器可得到相同 EXE。CI 使用独立输出目录构建，不复用工作区产物。每次交付必须同时提供 `SHA256SUMS.txt`，接收方必须先运行 `verify-checksums.ps1`。
