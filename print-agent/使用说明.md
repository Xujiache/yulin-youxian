# 禹邻优鲜 - 小票打印代理使用说明

## 📋 关于"每次重新连接打印机"的问题

### ✅ 好消息：配置已自动保存！

**打印代理会自动保存所有配置**，包括：
- ✅ API 地址
- ✅ 打印密钥（AccessKey）
- ✅ 打印机连接方式（USB/网络）
- ✅ 打印机路径

**配置文件位置**：`agent.config.json`（和程序同目录）

---

## 🚀 使用方法

### 方式 1：首次配置（仅需一次）

1. **双击运行**：`setup-agent.cmd`
2. **按提示填写**：
   - API 地址（如：`http://localhost:8080/api` 或 `https://yourdomain.com/api`）
   - 打印密钥（从管理后台生成并复制）
   - 选择打印机（自动检测，直接回车即可）
3. **测试打印**：自动打印测试小票
4. **完成**：配置已保存到 `agent.config.json`

### 方式 2：日常使用（直接运行）

**只需双击**：`run-agent.cmd`

程序会：
- ✅ 自动读取已保存的配置
- ✅ 自动连接打印机
- ✅ 自动接单打印

**无需重新输入任何信息！**

---

## 🔧 三种启动方式

### 1️⃣ 手动启动（推荐日常使用）
```
双击：run-agent.cmd
```
- 保持窗口运行
- 关闭窗口即停止打印

### 2️⃣ 开机自动启动（推荐门店使用）
```
双击：install-autostart.cmd
```
- 电脑开机自动运行打印代理
- 无需手动启动
- 适合门店长期使用

**取消开机启动**：
```
双击：uninstall-autostart.cmd
```

### 3️⃣ 重新配置
```
双击：setup-agent.cmd
```
- 仅在以下情况使用：
  - 更换打印机
  - 更换服务器
  - 打印密钥过期

## ❓ 常见问题

### Q1：我需要每次都输入密钥吗？
**A：不需要！** 密钥已保存在 `agent.config.json`，直接运行 `run-agent.cmd` 即可。

### Q2：电脑重启后需要重新配置吗？
**A：不需要！** 配置文件会保留。有两个选择：
- **方案 A**：重启后手动运行 `run-agent.cmd`
- **方案 B**：运行 `install-autostart.cmd` 设置开机自启

### Q3：更换打印机怎么办？
**A：重新运行配置向导**
```
双击：setup-agent.cmd
```
程序会自动检测新打印机并保存配置。

### Q4：如何查看当前配置？
**A：打开配置文件**
```
记事本打开：agent.config.json
```
可以看到所有已保存的配置项。

### Q5：打印密钥在哪里生成？
**A：在管理后台**
1. 打开管理后台
2. 点击左侧菜单「小票打印」
3. 点击「生成代理密钥」按钮
4. 复制密钥到打印代理

### Q6：能同时连接多台打印机吗？
**A：不能。** 一个打印代理只能连接一台打印机。如果需要多台打印机，需要：
1. 复制打印代理文件夹
2. 在每个文件夹中运行 `setup-agent.cmd` 配置不同的打印机

### Q7：配置文件丢失了怎么办？
**A：重新运行配置向导**
```
双击：setup-agent.cmd
```
重新填写配置即可。

| `run-agent.cmd` | 日常启动打印代理 | ⭐⭐⭐ 每天使用 |

## ⚠️ 注意事项

### 1. 不要删除配置文件
`agent.config.json` 包含所有配置，删除后需重新配置。

### 2. 保护打印密钥
打印密钥相当于打印机的"钥匙"，不要泄露给他人。

### 3. 保持程序运行
打印代理运行时，请保持窗口打开。关闭窗口会停止自动打印。

### 4. 网络连接
确保打印代理所在电脑能访问后端服务器（API 地址）。

### 5. 打印机连接
- USB 打印机：保持 USB 线连接
- 网络打印机：确保在同一网络

## 💡 优化建议

### 方案 1：使用开机自启（最推荐）
```
双击：install-autostart.cmd
```
**优点**：
- ✅ 电脑重启自动运行
- ✅ 无需每次手动启动
- ✅ 适合长期使用

### 方案 2：创建桌面快捷方式
1. 右键 `run-agent.cmd`
2. 选择「发送到」→「桌面快捷方式」
3. 重命名为「启动打印代理」

**优点**：
- ✅ 桌面一键启动
- ✅ 方便快捷

### 方案 3：固定到任务栏
1. 创建桌面快捷方式（方案 2）
2. 右键快捷方式 → 固定到任务栏

**优点**：
- ✅ 任务栏一键启动
- ✅ 更加便捷
