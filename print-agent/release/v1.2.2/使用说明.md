# 禹邻优鲜小票打印代理

版本：1.2.2

## 安全要求

- 生产 API 地址必须是 `https://你的正式域名/api`。程序会直接拒绝生产 HTTP。
- HTTP 仅用于本机开发，且只允许 `http://localhost:8080/api`、`127.0.0.1` 或 IPv6 回环地址。
- API 地址必须以 `/api` 结尾，不能含用户名、密码、查询参数或片段；代理不会跟随 HTTP 重定向，避免把密钥转发到其他主机。
- 打印密钥输入时不回显；使用 Windows DPAPI 按“当前 Windows 用户”加密后写入 `agent.config.json`，文件中不保存明文。
- `agent.config.json` 的 Windows ACL 只授予配置用户访问。
- 必须用配置时的同一个 Windows 用户运行和安装开机自启；换用户后应重新执行配置。
- 不要把 `agent.config.json`、日志、截图中的密钥或门店令牌发给他人。
- 同一 Windows 会话只允许一个代理实例，避免一张小票被多个进程竞争领取。

## 首次安装

1. 解压到固定目录，例如 `C:\禹邻优鲜\打印代理`，之后不要移动。
2. 打开 PowerShell，在目录中执行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify-checksums.ps1
   ```

   只有显示“SHA256 verification passed”才继续。`setup-agent.cmd` 和监督脚本也会自动复核。校验失败时重新下载，不要运行。
   SHA256 只能证明文件与清单一致，不能单独证明发布者身份；在 EXE 完成 Authenticode 签名之前，还必须通过独立可信渠道核对 `SHA256SUMS.txt` 自身的摘要。
3. 双击 `setup-agent.cmd`。
4. 填写 HTTPS API 地址和管理后台生成的打印代理密钥。
5. 按向导完成打印机测试和后端连通测试。
6. 双击 `install-autostart.cmd`。任务计划程序会使用同一 Windows 用户启动监督脚本。

## 日常运行与自动恢复

- 手动运行：双击 `run-agent.cmd`。
- 自动运行：安装开机自启后，登录 Windows 即启动。
- `supervise-agent.ps1` 会在代理异常退出后重启，重试间隔逐步增加到最多 60 秒。
- 任务计划程序也配置了失败重启，且禁止同一用户重复启动多个代理实例。
- 取消自启：双击 `uninstall-autostart.cmd`，它会先停止任务再删除。

## 配置与日志

| 文件 | 用途 |
| --- | --- |
| `agent.config.json` | API、打印机信息和 DPAPI 密文；仅配置用户可解密 |
| `print-agent.log` | 代理业务日志 |
| `supervisor.log` | 进程退出与重启日志 |
| `SHA256SUMS.txt` | 发布文件校验和 |
| `VERSION.txt` | 当前版本 |
| `BUILD-TOOLCHAIN.txt` | 编译器与供应商 SDK 摘要 |

两个日志都会自动轮转，最多保留当前文件和 5 个历史文件，不会无限增长。排障时可提供日志，但不要提供 `agent.config.json`。

## 常见问题

### 提示“生产 API 必须使用 HTTPS”

正式门店不能绕过此检查。先给域名配置有效 TLS 证书，再填写 `https://.../api`。不要把公网 IP 或域名改成 HTTP。

### 提示“打印密钥无法解密”

当前 Windows 用户与首次配置用户不同，或配置从另一台电脑复制而来。切回原用户，或删除本机 `agent.config.json` 后重新运行 `setup-agent.cmd`。不要尝试手工修改密文。

### 程序退出后没有恢复

检查任务计划程序中的 `YulinYouxianPrintAgent`，再查看 `supervisor.log`。确认程序目录未移动、Windows 用户未变。

### 需要更换打印机或密钥

1. 先在任务计划程序停止 `YulinYouxianPrintAgent`，确认旧代理已退出；重复实例门禁会拒绝边运行边改配置。
2. 只有在集成版本已确认后台支持“新旧密钥短时并存”时，才先签发新密钥；后台入口、接口和字段名称由集成 Agent 的最终契约为准，本代理文档不猜测。
3. 使用原 Windows 用户重新运行 `setup-agent.cmd`，粘贴新密钥并完成测试打印和后端连通测试。
4. 重新启动任务，确认后台显示代理在线并完成一张测试小票。
5. 最后撤销旧密钥并记录操作者、时间、门店、代理版本和验证结果。若后台不支持并存，必须安排维护窗口，不能提前撤销旧密钥。
6. 怀疑泄露时立即停任务、撤销旧密钥、签发新密钥并检查服务端安全审计日志；不要在聊天或工单中发送密钥。

## 发布人员

构建命令：

```powershell
.\print-agent\build.ps1 -OutputDirectory "$env:TEMP\YulinPrintAgent-1.2.2"
```

版本目录不可覆盖；要发布新版本时先递增源码版本，再生成新的版本目录。构建脚本会校验供应商 DLL 固定摘要、验证系统编译器签名，并规范化旧版 C# 编译器写入的 PE 时间戳和 MVID；同一源码、编译器与 SDK 可得到相同 EXE。`BUILD-TOOLCHAIN.txt` 记录输入摘要，CI 使用独立输出目录连续构建两次并执行清单验证。每次交付必须同时提供 `SHA256SUMS.txt`，并通过独立可信渠道交付该清单自身的 SHA256。当前 EXE 尚无 Authenticode 发布者签名，这是交付前需要外部代码签名证书解决的阻塞。
