# 禹邻优鲜 - 小票打印代理

## 📦 安装说明

### 第一步：解压文件
将压缩包解压到任意位置（建议：`C:\禹邻优鲜\打印代理`）

### 第二步：首次配置
双击运行：`setup-agent.cmd`

按提示填写：
1. **API 地址**：您的后端服务器地址（如：http://localhost:8080/api）
2. **打印密钥**：从管理后台生成（管理后台 → 小票打印 → 生成代理密钥）
3. **选择打印机**：程序会自动检测 USB 打印机，直接回车即可

### 第三步：选择启动方式

#### 方式 1：开机自动启动（推荐门店使用）⭐
双击运行：`install-autostart.cmd`

**效果**：
- ✅ 电脑开机自动运行打印代理
- ✅ 无需每天手动启动
- ✅ 适合长期使用

**取消自启**：双击 `uninstall-autostart.cmd`

#### 方式 2：手动启动（开发测试）
每次双击运行：`run-agent.cmd`

**效果**：
- 需要时手动启动
- 关闭窗口停止打印

## ❓ 常见问题

### Q1：需要每次都重新配置吗？
**不需要！** 配置会自动保存，之后直接运行 `run-agent.cmd` 或使用开机自启。

### Q2：支持哪些打印机？
支持所有 Xprinter 品牌的 USB 热敏打印机（58mm/80mm）。

### Q3：打印密钥在哪里生成？
管理后台 → 小票打印 → 点击"生成代理密钥"按钮 → 复制密钥。

### Q4：配置保存在哪里？
自动保存在 `agent.config.json` 文件中，请勿删除。

### Q5：电脑重启后需要重新配置吗？
不需要！配置会保留。建议使用开机自启功能，重启后自动运行。

## ⚠️ 注意事项

1. **不要删除任何文件**：所有文件都是必需的
2. **保护打印密钥**：不要泄露给他人
3. **保持网络连接**：确保能访问后端服务器
4. **保持打印机连接**：USB 线或网络连接稳定
