========================================
   禹邻优鲜  小票打印机  安装说明
========================================

本程序只需在门店那台连着打印机的 Windows 电脑上安装。


【 安装前的准备 】

1. 把打印机插好电、连好电脑。
   - USB 线连接：需要先安装一次「芯烨 58 系列打印机驱动」(向管理员索取或到芯烨官网下载)。
   - 网口 / Wi-Fi 连接：不用装驱动，但要和电脑连在同一个网络里。
2. 打印机里放好打印纸。
3. 确认后端服务器地址（向管理员索取，通常是 http://你的域名/api 或 http://内网IP:8080/api）。
4. 准备好管理员发给你的「打印密钥」(一长串字母数字)。
5. 管理员需在后台「小票打印」页面确认已启用自动打印并生成代理密钥。


【 安装步骤 】

第一步：把这个压缩包解压到桌面。
        解压后会得到一个文件夹，里面所有文件必须放在一起，不要拆开、不要删。

第二步：双击运行  setup-agent.cmd
        按屏幕提示操作（共 5 步）：

          第 1 步 — 填写后端 API 地址
            默认：http://localhost:8080/api
            生产环境：https://你的域名/api
            注意：末尾必须带 /api

          第 2 步 — 填写打印密钥
            粘贴管理员在后台生成的代理密钥，按回车。

          第 3 步 — 连接打印机
            程序会自动查找 USB 打印机，找到就直接用。
            如果是 Wi-Fi 打印机，按提示填写打印机的 IP 地址。

          第 4 步 — 打印测试小票
            程序自动发送一张测试小票到打印机。
            ==> 只要吐出一张小票，说明打印机硬件正常！

          第 5 步 — 验证后端连通性
            程序自动连接后端服务器，注册代理。
            ==> 显示"后端连接成功"即可进入下一步。

        全部通过后，程序会自动进入接单打印模式，保持窗口运行即可。

第三步：双击运行  install-autostart.cmd
        设置开机自动启动。以后这台电脑一开机就会自动接单打印，
        不用再手动打开程序。


【 验证打印链路 】

1. 登录管理后台 → 小票打印页面。
2. 确认「门店打印代理」显示为绿色「在线」。
3. 点击「测试打印」按钮，确认打印机吐出一张测试小票。
4. 链路通畅！后续订单支付成功后将自动打印。


【 日常使用 】

- 客户在小程序下单并支付成功后，门店这台电脑会自动打印小票。
- 请保持这台电脑「开机 + 联网」。电脑关机或断网就打不出小票。
- 如果某张小票没打出来，可以联系管理员在后台「小票打印」页面查看，
  失败的任务可以点「补打」重新打印。
- 如果控制台窗口被关闭，程序会停止。双击 run-agent.cmd 可重新启动。


【 常见问题 】

问：双击 setup-agent.cmd 没反应 / 一闪而过？
答：在文件上点右键 → 以管理员身份运行。

问：第 3 步找不到 USB 打印机？
答：检查打印机电源、数据线；USB 连接请确认已装芯烨驱动；
    然后重新双击 setup-agent.cmd 再试一次。
    也可以手动填写打印机的 Wi-Fi/IP 地址。

问：第 4 步测试小票打不出来？
答：检查打印机电源、数据线、是否有纸；
    确认打印机型号为芯烨 XP-58 系列；
    然后重新双击 setup-agent.cmd 再试一次。

问：第 5 步后端连接失败？
答：检查 API 地址是否正确（可重新运行 setup-agent.cmd 修改）；
    确认后端服务器已启动且网络可达；
    确认打印密钥已由管理员在后台生成；
    确认防火墙没有阻止连接。

问：管理后台显示代理「离线」？
答：确认门店电脑上的打印代理程序正在运行（窗口未关闭）；
    确认网络通畅，能访问后端 API 地址；
    在管理后台检查代理密钥是否已配置。

问：想取消开机自动启动？
答：双击运行 uninstall-autostart.cmd。

问：想手动启动一次程序？
答：双击运行 run-agent.cmd。

问：想修改 API 地址或打印密钥？
答：重新双击 setup-agent.cmd，按提示修改配置即可。


如遇无法解决的问题，请把屏幕上的提示截图发给管理员。
