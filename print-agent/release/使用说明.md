# 禹邻优鲜小票打印代理

版本：1.2.1

## 安全要求

- 生产 API 地址必须是 `https://你的正式域名/api`。程序会直接拒绝生产 HTTP。
- HTTP 仅用于本机开发，且只允许 `http://localhost:8080/api`、`127.0.0.1` 或 IPv6 回环地址。
- 打印密钥使用 Windows DPAPI 按“当前 Windows 用户”加密后写入 `agent.config.json`，文件中不再保存明文。
- 必须用配置时的同一个 Windows 用户运行和安装开机自启；换用户后应重新执行配置。
- 不要把 `agent.config.json`、日志、截图中的密钥或门店令牌发给他人。

## 首次安装

1. 优先使用 `release/v1.2.1` 版本目录，不要覆盖正在运行的旧目录。
2. 打开 PowerShell 并执行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify-checksums.ps1
   ```

3. 校验通过后双击 `setup-agent.cmd`。
4. 填写 HTTPS API 地址和管理后台生成的打印代理密钥。
5. 完成打印测试和后端连通测试。
6. 双击 `install-autostart.cmd`。

## 自动恢复

- `supervise-agent.ps1` 会在代理异常退出后重启，重试间隔最多 60 秒。
- 任务计划程序配置失败重启，并禁止重复启动多个实例。
- `print-agent.log`（5 MB）和 `supervisor.log`（2 MB）均自动轮转、保留 5 份。
- 取消自启时运行 `uninstall-autostart.cmd`。

配置只能由创建它的 Windows 用户解密。提示“打印密钥无法解密”时，应切回原用户或重新执行 setup，不能复制其他电脑的配置密文。
