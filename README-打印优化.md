## 🎯 正确的使用流程

### 第一次使用（配置阶段）
```
1. 双击：setup-agent.cmd
2. 填写配置（API地址、打印密钥、选择打印机）
3. 配置自动保存到 agent.config.json
```

### 之后每次使用（直接运行）
```
双击：run-agent.cmd

✅ 自动读取配置
✅ 自动连接打印机
✅ 自动开始打印

无需重新输入任何信息！
```

## 🚀 三种使用模式

### 模式 1：手动启动（开发/测试）
**适用场景**：临时测试、开发调试

**操作**：
```
双击：run-agent.cmd
```

**特点**：
- 需要时手动运行
- 关闭窗口停止打印
- 适合不常用的场景

---

### 模式 2：开机自启（门店推荐）⭐
**适用场景**：门店长期使用、无人值守

**操作**：
```
1. 首次配置：setup-agent.cmd
2. 设置自启：install-autostart.cmd
```

**特点**：
- ✅ 电脑开机自动运行
- ✅ 无需每次手动启动
- ✅ 真正的"一次配置，永久使用"
- ✅ 最省心的方案

**取消自启**：
```
双击：uninstall-autostart.cmd
```

---

### 模式 3：桌面快捷方式
**适用场景**：需要手动控制，但希望方便启动

**操作**：
```
1. 右键 run-agent.cmd
2. 发送到 → 桌面快捷方式
3. 重命名为「启动打印代理」
```

**特点**：
- 桌面一键启动
- 比进文件夹方便
- 仍需手动启动

## 🔍 常见误区

### ❌ 误区 1：每次都运行 setup-agent.cmd
**错误**：每次都重新配置

**正确**：
- `setup-agent.cmd` 只在首次使用或更换设备时运行
- 日常使用直接运行 `run-agent.cmd`

---

### ❌ 误区 2：关闭电脑就要重新配置
**错误**：以为配置会丢失

**正确**：
- 配置保存在 `agent.config.json`
- 电脑重启配置依然存在
- 只需重新运行 `run-agent.cmd`
- 或设置开机自启，连这步都省了

---

### ❌ 误区 3：不知道有开机自启功能
**错误**：每天手动启动

**正确**：
- 使用 `install-autostart.cmd` 设置开机自启
- 之后电脑开机自动运行打印代理
- 真正的一劳永逸
