# 随机减免与分享触发

## 1. 功能范围

随机减免在待支付订单上运行。符合金额阶梯的用户可以：

1. 原价支付，不参加活动；
2. 进入专用活动页，手动点击微信右上角菜单并选择“分享到朋友圈”；
3. 菜单事件被服务端记录后获得一次抽奖资格；
4. 抽中现金减免、随单实物赠品或谢谢惠顾；
5. 按服务端锁定后的最终金额本人支付，或生成好友代付链接。

抽奖主体、减免和赠品均归订单发起人。好友代付人只能查看付款摘要并支付，不能抽奖或修改结果。

## 2. 微信能力边界

微信小程序不允许页面代码直接拉起朋友圈分享，也不提供“最终发布成功、取消或失败”的回调。
本功能的 `share-trigger` 口径只能确认 `Page.onShareTimeline` 被调用，即用户点击了右上角
“分享到朋友圈”入口，不能证明内容最终发布。

朋友圈打开活动页时处于场景值 `1154` 的单页模式：

- 没有登录态，不能调用 `wx.login`；
- 不能跳转其他页面；
- 本地存储与普通小程序不共享；
- 页面只读取公开活动展示接口，不读取订单或用户信息。

“分享后获得概率性收益”存在微信平台审核风险。生产上线前必须由运营确认规则、文案和审核策略，
不得在产品说明中声称系统能够验证朋友圈最终发布成功。

## 3. 活动配置

管理后台入口：

- `营销中心 / 随机减免`
- `营销中心 / 中奖记录`

单活动配置包含：

- 总开关、开始/结束时间；
- 单用户每日次数；
- 每日现金减免预算；
- 分享标题、描述和图片地址；
- 一个或多个商品金额阶梯；
- 每个阶梯下的现金减免、实物赠品和谢谢惠顾奖项；
- 奖项整数权重、启停、排序和实物营销库存。

金额全部以“分”传输。阶梯按 `productAmount` 匹配，采用左闭右开区间 `[min, max)`，
最后一个启用阶梯可以不设置上限。禁用、零权重、营销库存耗尽或实际商品库存不足的奖项不参与抽取。

实物奖项必须绑定已上架商品；多规格商品还必须绑定 SKU。后台修改赠品总库存时，服务端保留已消耗数量，
不会使用浏览器中的旧“剩余库存”覆盖实时抽奖结果。

## 4. 金额、支付和好友代付

现金结果直接写入订单促销投影并降低 `payableAmount`。微信下单、支付回调金额校验、可退金额和退款
总额全部继续以 `payableAmount` 为唯一锚点。

应用现金减免前会关闭旧微信预支付单并轮换 `out_trade_no`，避免旧金额支付成功后无法确认订单。
同一订单存在有效好友代付链接时禁止抽奖；生成代付链接前会把订单决策锁定为“已抽取”或“已跳过”。

代付摘要展示商品金额、配送费、包装费、随机减免和最终支付金额，但不暴露收货地址、订单状态和配送进度。

## 5. 实物赠品履约

实物中奖时同时预留：

- `marketing_lottery_prize.stock_remaining` 中的营销库存；
- Storefront 商品或 SKU 的一份实际库存。

赠品不计入商品金额、起送价或退款商品金额，但会进入：

- 用户订单详情的“鲜礼赠品”行；
- 管理后台订单促销投影；
- 小票“鲜礼赠品（随单配送）”区域；
- 配送任务的商品摘要、件数和赠品摘要。

待支付订单超时关闭时释放赠品库存；重启支付时重新预留并保留原抽奖结果。订单取消不返还用户当日抽奖次数。
全额退款发生在履约前时撤销赠品；已经随单送达的赠品不追缴，记录为营销成本。

## 6. 数据与一致性

Flyway `V10__create_marketing_lottery.sql` 新增活动、阶梯、奖项、挑战、抽奖、赠品和订单决策表，
并给 `delivery_task` 增加减免与赠品快照字段。V1–V9 不得修改。

抽奖流水和库存使用关系表；`application_state` 的 storefront 快照只保存按订单索引的最终促销投影。
关系表先写 `RESERVED`，Storefront 应用成功后改为 `APPLIED`，失败则补偿库存并作废。
定时一致性检查会修复缺失投影，或清理无法应用的保留流水。

2. 确认 7 张 `marketing_lottery_*` 表存在，`delivery_task` 包含
   `marketing_discount_amount` 和 `marketing_gift_summary`。
3. 后台先保持活动关闭，配置阶梯、奖项、预算和库存后再开启。
4. 分别真机验证 Android 和 iOS 的朋友圈菜单、取消分享、切后台、弱网恢复和场景值 `1154`。
5. 验证现金减免支付回调、退款、订单超时重启、赠品库存恢复和好友代付最终金额。
6. 验证门店打印代理已升级，能够打印随机减免和随单赠品。
