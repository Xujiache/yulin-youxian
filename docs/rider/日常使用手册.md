# 第一部分 · 店主篇

## 1.1 每天开店后，先花 2 分钟做这三件事

打开电脑浏览器 → `https://hqhjxt.vip` → 登录 → 左侧「禹邻优鲜 → 配送调度台」

### ① 看右上角的连接状态

| 显示什么 | 意思 | 要不要管 |
| --- | --- | --- |
| 🟢 实时连接正常 | 一切正常 | 不用管 |
| 🟡 实时连接已断开，正在 5 秒轮询 | 页面还能用，只是数据慢 5 秒才更新 | 点旁边的「立即重连」。还不行就刷新页面 |

### ② 看「在岗骑手」那一列

送货的人（你自己）必须在这一列里出现，才说明他已经在手机上点了「上班」。

**这一列是空的 = 没有人在岗 = 系统没法派单。**

### ③ 看有没有红色数字

页面顶部有六个小方块：待派 / 在途 / 超时风险 / 未关闭异常 / 在岗骑手 / 空闲骑手。

**"超时风险"和"未关闭异常"这两个数字变红，说明有事要处理。**点一下方块，下面的队列会自动筛选出对应的单。

## 1.2 一个订单从下单到送达，完整走一遍

### 全流程图

```
① 顾客在小程序下单、付款
        ↓
② 后台「订单管理」出现新订单，状态「已支付/待接单」
        ↓
③ 你点「接单」，状态变成「备货中」
        ↓
④ 你去拣货、称重、打包
        ↓
⑤ 【★关键★】你在后台点「拣货完成」
        ↓
⑥ 系统生成配送任务，等 0～2 分钟看有没有顺路的单可以一起送
        ↓
⑦ 系统自动派给在岗的送货人，手机响铃 + 语音播报
        ↓
⑧ 送货人在手机上「接单」→「取货核对」→ 订单自动变「配送中」
        ↓
⑨ 送货人按系统排好的顺序送，顾客在小程序上看到骑手在动
        ↓
⑩ 送到后拍照 + 滑动确认 → 订单自动变「已完成」
```

### 🔴 第 ⑤ 步：「拣货完成」，把这一步讲透

**这是整套配送系统唯一的开关。不点它，后面 ⑥⑦⑧⑨⑩ 全都不会发生。**

#### 为什么是"拣货完成"而不是"下单"？

假设顾客早上 8:00 下单，你 8:40 才把菜称好打包好。

- 如果系统在 8:00 下单时就派单，送货的人 8:00 就跑到店里来了，然后**干等 40 分钟**
- 系统在 8:00 就开始算"预计送达时间"，等真的出发时，时间早就不准了

所以派单的起点定在**东西已经打包好、可以拿走**的那一刻。这样：
- 送货的人一到店就能拿走，不用等
- 预计送达时间从这一刻开始算，比较准
- 那 40 分钟里如果又来了顺路的单，还能一起打包出去

#### 不点会怎样？

| 现象 | 原因 |
| --- | --- |
| 手机上一直收不到新单 | 没生成配送任务 |
| 调度台「待派积压」一直是 0 | 同上 |
| 顾客小程序上看不到地图，只有一句"商家正在配送中" | 同上 |
| 送到了也得回后台手动点"已完成" | 同上 |

**所以：每天最重要的一个习惯就是——包好一单，回后台点一下「拣货完成」。**

#### 这个按钮在哪、点了会怎样

配送功能打开之后，订单页上原来那个「配送」按钮就变成了绿色的「**拣货完成**」——位置没变，还在每一行最右边的操作栏里，「接单」按钮的旁边。

点它 → 弹出一个「拣货完成」的确认框 → 填几项（见下）→ 点「**确认拣货完成**」→ 屏幕上提示"已生成配送任务，系统将自动派单"。这一单就进入前面流程图里的 ⑥⑦⑧⑨⑩ 了。

同时订单列表上还会多出一列「**配送**」：这一单派给了谁、走到哪一步了、预计几点送到，都显示在这一列，点「查看任务」能跳到这一单的配送详情。

#### 点的时候会让你填什么

确认框里一共四项，都是给送货和排顺序用的：

| 填什么 | 干什么用 | 不填行不行 |
| --- | --- | --- |
| 件数 | 送货人到店核对，防止漏拿。**系统会照订单里的商品条数先帮你填好**，不对再改 | 有默认值，一般不用动 |
| 总重（kg） | 判断一趟能不能带得动、要不要拆成两趟 | 行，但合单会不准。默认是 0 |
| 冷链等级 | 决定这单能不能排在最后一站 | **建议选**。有冻品不选的话，可能被排到最后一站化掉 |
| 拣货备注 | 选填，最多 120 个字。称重跟顾客下单的量有出入时写在这里，比如"西红柿实称 1.05 kg" | 行 |

> **这个框里没有拍照的地方。** 只有上面这四项，传不了电子秤照片。顾客事后说"少了二两"的时候，你能翻出来的是这里填的总重和拣货备注——在「配送任务 → 详情 → 事件时间轴」里能看到，永久保存。
>
> 所以：**称重有出入的、或者以前跟你争过分量的顾客，一定把实称多少写进拣货备注**，这是目前唯一能留下的凭据。

#### 点之前订单必须是「备货中」

如果订单还是「已支付/待接单」，点「拣货完成」会被拒绝，提示"必须为备货中"。**先点「接单」，再点「拣货完成」。**

多单一起打包好的时候，在列表里把这几单勾上，点上方工具栏的「**批量拣货完成（N）**」，一次性搞定。批量的时候不用一单一单填——系统会照每张订单的明细自动带出件数和重量。其中哪一单需要精确称重，就单独回到它那一行点「拣货完成」再填一次。

### 第 ⑥ 步：为什么要等 0～2 分钟？

这叫**压单**。系统不会一有单就立刻派出去，而是先等一会儿，看看这两分钟里会不会又出来一个地址挨着的单——如果有，就把两单打包成"一趟"一起送。

跑一趟送两单，比跑两趟送两单省一半的路。

等待时间可以改：后台「调度参数 → 派单 → 压单窗口（秒）」，现在是 **120 秒**。

| 改成 | 效果 |
| --- | --- |
| 0 | 一有单立刻派，绝不等。适合单量很少、顾客催得紧 |
| 120（现在） | 平衡 |
| 180（最大） | 最省路，但每单都会晚两三分钟出发 |

如果某一单很急不想等，在调度台的「待派积压」里找到它，直接点「立即派单」，跳过等待。

### ⚠️ 一个操作习惯的变化：微信发货单

启用配送系统之后，订单页上原来那个「配送」按钮变成了「拣货完成」。**原来点「配送」会自动下载一个微信发货单的 Excel，现在这个自动下载没有了**——因为订单不再是你手动点成"配送中"，而是等送货的人在手机上点「已取货」时自动变。

如果你还需要这个 Excel，在订单页的批量工具栏里有一个**独立的「导出微信发货单」按钮**：先在列表里把要导的单勾上，再点这个按钮就能生成下载。只要顾客已经付过款（待接单、备货中、配送中、已完成、部分退款都算），什么时候导都行，**导出不会改动订单状态**。功能没少，只是位置换了、需要自己勾一下。

## 1.3 调度台的四列队列：每一列是什么，看到什么要动手

调度台的主界面是**四列卡片**，不是地图。**地图只是辅助，没有地图也能完成全部工作。**

### 第一列：待派积压（红点）

**这里是"已经打包好、但还没派出去"的单。**

排序：按压单到期时间，**最快要派出去的排在最上面**。

| 卡片上的信息 | 意思 |
| --- | --- |
| 任务号 | 系统给的编号 |
| 🧊 冷链 / 远单 / 已改派 N 次 | 标签 |
| 右上角的倒计时 | 还有多久到承诺送达时间。**不足 5 分钟会变红** |
| 件数 / 重量 / 承诺时间 / ETA | 货物和时间信息 |

**四个按钮**：

| 按钮 | 什么时候用 |
| --- | --- |
| **立即派单** | 不想等压单，马上派给系统推荐的人 |
| **指派给…** | 想自己挑人（人多的时候用） |
| **查看建议** | 看系统为什么推荐这个人：会新增多少里程、预计几点送到 |
| **取消** | 这单不送了。**订单会退回"备货中"状态**，需要填原因 |

也可以**直接把卡片拖到右边"在岗骑手"列的某个人身上**，拖过去就是派给他。

#### 🔴 这一列一直不为 0 怎么办？

| 可能原因 | 怎么确认 | 怎么解决 |
| --- | --- | --- |
| 没人在岗 | 看第四列是不是空的 | 让送货的人在手机上点「上班」 |
| 自动派单被关了 | 看页面右上角「自动派单」开关 | 打开它（这个开关的副作用见 1.7 节） |
| 在岗的人手上单太多了 | 看第四列骑手卡片上的"3/3"这种数字 | 等他送完几单，或者点「立即派单」强制派 |
| 顶部出现黄色"运力预警"横幅 | 单子比人能送的多 | 加人，或者跟顾客商量延后 |

### 第二列：在途超时风险（黄点）

**这里是"已经在路上、但可能会迟到"的单。**

排序：**剩下时间最少的排最上面**。不足 5 分钟标红。

| 按钮 | 什么时候用 |
| --- | --- |
| **改派** | 当前送货的人来不及了，换个人。需要填原因，会留记录 |
| **联系骑手** | 给送货的人发一条 APP 内消息（他手机上会看到） |
| **联系顾客** | 弹出顾客的姓名、电话、地址，可以一键复制号码打过去 |

#### 🔴 看到红色怎么办？

**一个人送货的情况下，"改派"派给谁都是你自己，没意义。所以红色的正确处理方式是：**

1. 点「联系顾客」，打个电话说一声"路上有点堵，晚 10 分钟到"
2. 主动说一声比顾客打过来投诉强很多
3. 如果确实送不了，让送货的人在 APP 上上报异常（选"天气恶劣"或"车辆故障"），单子会挂起来等你处理

### 第三列：未关闭异常（紫点）

**这里是送货的人在手机上上报的问题。**

排序：按严重程度，紧急的在最上面。

每张卡片显示：异常类型、任务号、订单号、上报人、上报时间、描述、**现场照片**。

点「处理」会弹出一个框，让你选怎么办 —— 详见 1.4 节。

#### 🔴 这一列不为 0，必须当天处理完

未关闭的异常会一直挂在这里。挂着的单：
- 订单状态卡住不动
- 顾客那边看到的进度也是卡住的
- 第二天这一列会越堆越多，最后你就不看它了 —— **这是最危险的**

**养成习惯：晚上收工前把这一列清空。**

### 第四列：在岗骑手（绿点）

**这里是"现在点了上班"的送货人。**

排序：按手上的活儿多少，**闲的在最上面**。

| 卡片上的信息 | 意思 |
| --- | --- |
| 姓名、工号 | —— |
| 2/3 这样的数字 | 手上有 2 单，最多能同时接 3 单 |
| 定位时间 | 最后一次上报位置是什么时候 |
| 🔴 **定位陈旧** 标记 | **超过 2 分钟没上报位置了** |

| 按钮 | 什么时候用 |
| --- | --- |
| **派单** | 主动挑几个单派给他，会自动建成一趟 |
| **轨迹** | 看他今天走过的路线 |
| **消息** | 发一条消息到他手机上 |
| **强制下班** | ⚠️ 会立刻把他的 APP 登出，手上没送完的单需要重新派。只在手机丢了、人联系不上时用 |

#### 🔴 出现"定位陈旧"红标怎么办？

**这是最需要立刻处理的情况。**位置不动了，说明手机上的 APP 被系统冻结了。

按顺序试：

1. **打电话让他把 APP 打开看一眼**（很多时候点亮屏幕、打开 APP 就恢复了）
2. 如果打开 APP 后位置立刻恢复 → 说明手机把 APP 后台冻结了 → **当天回来后重做一遍保活向导**
3. 如果打开 APP 也不恢复 → 让他看手机是不是没信号、是不是开了飞行模式、系统定位总开关是不是被关了
4. 都不行 → 让他下班再上班一次

## 1.4 异常怎么处理

送货的人在手机上能上报 **13 种**问题。你在后台看到之后要选一个处理方式。

### 13 种异常类型和建议处理方式

| 异常类型 | 通常什么情况 | 建议怎么处理 |
| --- | --- | --- |
| 顾客联系不上 | 打电话没人接 | 你自己再打一次。打通了选「继续配送」；实在联系不上选「退回门店」 |
| 地址错误 | 导航到的地方不对 | 打电话问清楚。地址在附近选「继续配送」；差很远选「退回门店」 |
| 顾客拒收 | 顾客说不要了 | 选「退回门店」。要不要退款自己决定，需要退就再选「发起退款」 |
| 商品破损 | 路上压坏了 | 看照片。轻微的选「继续配送」并跟顾客解释；严重的选「发起退款」 |
| 商品漏液 | 酱油醋之类漏了 | 同上。漏得厉害要提醒送货人别污染同车其他单 |
| 缺斤少两争议 | 顾客觉得少了 | 调出拣货时填的总重和拣货备注对一下（「配送任务 → 详情 → 事件时间轴」）。真少了选「发起退款」 |
| 缺件少件 | 少装了东西 | 自己核对拣货单。确实少了就补送或退款 |
| 门禁进不去 | 小区不让进 | 电话让顾客下来拿。拿到了选「继续配送」 |
| 车辆故障 | 电动车没电、坏了 | 选「退回门店」，货带回来重新安排 |
| 身体不适 | 人不舒服 | 选「退回门店」，先顾人 |
| 天气恶劣 | 下大雨大雪 | 选「继续配送」（慢点送）或跟顾客商量改期 |
| 门店出货慢 | 到店了东西还没好 | 这条通常是提醒你自己的。选「继续配送」 |
| 其他 | 上面都不是 | 看描述和照片决定 |

### 六个处理选项分别是什么意思

| 选项 | 系统会做什么 |
| --- | --- |
| **继续配送** | 问题解决了，送货人接着送这一单 |
| **退回门店** | 货带回店里，这一单的配送任务结束，订单需要你另行处理 |
| **改派骑手** | 换个人送（一个人的时候用不上） |
| **发起退款** | 进入售后退款流程，之后在「售后退款」页面继续操作 |
| **取消配送** | 订单取消，任务终止 |
| **忽略** | 误报，直接关掉 |

还有一个「免除骑手责任」开关，**默认是打开的**。你自己家送货，这个开关不用管。

### 处理时的两条建议

1. **备注一定要填。**填了以后这条记录会永久保存，以后翻账、跟顾客对质都用得上。
2. **先看照片再决定。**送货人上报时拍的照片就在弹窗里，点开能放大。

## 1.5 怎么加新的送货人员（比如家里人）

### 第一步：在后台建账号

1. 左侧菜单「禹邻优鲜 → 骑手管理」
2. 点右上角「新增骑手」
3. 填这几项：

| 字段 | 填什么 | 必填 |
| --- | --- | --- |
| 姓名 | 真实姓名 | ✅ |
| 手机号 | **这个手机号就是登录账号**，要填能用的 | ✅ |
| 车辆类型 | 电动车 / 摩托车 / 自行车 / 汽车 / 步行 | ✅ |
| 车牌号 | 有就填 | ❌ |
| 最多同时接几单 | 默认值就行。新手建议填 3 | ❌ |
| 最大载重（kg） | 保温箱能装多少。默认值就行 | ❌ |
| 健康证有效期 | 有就填。**过期了系统不会拦人**（这条已经关掉） | ❌ |
| 试用期 | 新人建议勾上。勾了之后系统只会派近的、少的单给他 | ❌ |

4. 点「保存」

### 🔴 第二步：立刻抄下初始密码

保存成功后，屏幕上会弹出一个**初始密码**。

**这个密码只显示这一次，关掉窗口就再也看不到了。**

抄在纸上，或者截图。忘了的话只能回到骑手列表点「重置密码」重新生成一个。

### 第三步：在他手机上装 APP

1. 把 `禹邻优鲜骑手.apk` 发到他手机上（微信或数据线）
2. 安装（会遇到"未知来源"的拦截，详细步骤见《安装部署手册》6.4 节）
3. 用手机号 + 初始密码登录
4. 系统强制要求改密码，让他改一个自己记得住的
5. 跟着引导做完三步授权
6. **陪着他做完保活向导**（15 分钟，不能让他自己回家做）
7. 让他点一次「上班」，你在后台「配送调度台」第四列能看到他，就成功了

### 试用期是什么

勾了"试用期"的人，系统会：
- 最多同时给他 3 单（正常人是按设定值）
- 只派 **2 公里以内**的近单给他

熟悉了之后，回「骑手管理」编辑，把"试用期"取消勾选。

### 人不干了怎么办

「骑手管理」列表里点「停用」。停用后：
- 他的 APP 立刻被登出，登不进来
- 账号和历史记录都保留，以后想恢复点「启用」就行

**不要直接删账号**，删了历史配送记录会对不上。

## 1.6 怎么改门店坐标

**什么时候需要改**：第一次上线时必须改一次；店铺搬家时再改一次。

**为什么重要**：所有的距离、路线、送达时间都是从店门口开始算的。坐标偏 500 米，每一单的预计时间都会偏。

### 第一步：在高德地图上拿到经纬度

1. 手机打开**高德地图 APP**（不是百度地图，坐标体系不一样）
2. 搜索或滑到「兴泾镇市场西北门 中国黄金对面」，**把地图放到最大**，能看清店门口
3. **手指长按**店门口那个位置，屏幕上会掉下一个红色图钉
4. 屏幕底部会弹出一个卡片，上面显示一串数字，形如：

```
38.383423, 106.096144
```

5. 长按这串数字可以复制。

> **找不到经纬度怎么办**：有些版本的高德要点一下卡片展开才显示。实在找不到，就点卡片上的「分享」→「复制链接」，链接里带着 `location=106.096144,38.383423` 这样的参数（**注意分享链接里是经度在前**）。

### 第二步：填到后台

1. 电脑打开管理后台
2. 左侧「禹邻优鲜 → 调度参数」
3. 左边的分类列表里点「门店」
4. 找到两个输入框：

| 输入框 | 填哪个数 | 银川这边大概是多少 |
| --- | --- | --- |
| **门店纬度** | 前面那个 | **38** 点几 |
| **门店经度** | 后面那个 | **106** 点几 |

5. 点「保存」，不用重启，立即生效

### 🔴 别填反了

填反了的后果：系统会以为你的店在南极洲附近，每一单都会被标成"超远单"，预计送达时间会算成好几个小时。

**记住：银川的纬度是 38 开头，经度是 106 开头。**

### 第三步：检查有没有填对

- 有高德 Key 的话：打开「配送调度台」，看地图上的店铺图标是不是在兴泾镇
- 没有 Key 的话：随便找一个附近顾客的订单，看后台算出来的距离是不是合理（隔壁小区应该是几百米，不该是几十公里）

## 1.7 「调度参数」页面：哪些能改，哪些别碰

这个页面有 70 多个参数，分成十几个分类。**大部分你都不需要动。**

### 🟢 可以放心改的

| 参数 | 在哪个分类 | 什么时候改 |
| --- | --- | --- |
| 门店纬度 / 经度 | 门店 | 上线时、搬家时 |
| 压单窗口（秒） | 派单 | 觉得等太久（改小）或想更省路（改大） |
| 单波次最大单量 | 派单 | 保温箱装不下这么多单时改小 |
| 送达强制拍照 | 配送 | **现在是开着的**（你要求的） |
| 送达强制核销码 | 配送 | 现在关着。有纠纷的小区可以打开 |
| 远单标记半径（米） | 门店 | 觉得"远单"标签标得不合理时。**注意：这只是个标记，不会拒单** |

### 🔴 「自动派单总开关」：关掉它之前必须知道的事

这个开关（在「调度参数 → 派单」，调度台右上角那个「自动派单」也是同一个）现在管着**两件**事，不只是"自动还是手动"：

1. 关掉它，系统不再自动给人派单 —— 这是你以为会发生的
2. 关掉它，**订单页上的「拣货完成」按钮也会跟着消失**，变回原来那个「配送」按钮 —— 这一条容易漏

第 2 条的后果比较严重：连配送任务都建不出来，调度台的「待派积压」永远是空的，也就没有单可以"手动派"，整套配送等于停摆。而且页面上不会有任何提示告诉你为什么，很容易白折腾半天。

**所以：这个开关就别关。**关掉它得到的不是"手动派单模式"——**系统里根本没有"只手动派单"这个模式**，关掉就是整套配送不工作。

需要"自己控制某一单"的时候，用下面这两个按钮，不要动总开关：

- 想让某一单不等压单、马上出发 → 在「待派积压」里点那一单的「**立即派单**」
- 想让系统立刻跑一轮 → 调度台右上角「**手动触发调度**」

这两个按钮都不受这个开关影响，能达到你想要的效果，又不会把系统关停。

### 🔴 不要碰的

| 参数 | 为什么 |
| --- | --- |
| 五个"权重"（顺路度、超时风险、负载均衡、冷链、骑手等级） | 这是派单打分的配方，五个数字互相影响。改坏了派单会变得莫名其妙 |
| 电动自行车速度 | 国家标准规定的上限就是 15 km/h，改不上去，也不该改 |
| 保护时间下限、非对称分位数 | 算送达时间的内部参数 |
| 冷链惩罚系数、超时惩罚系数、过早到达惩罚系数 | 排顺序的内部参数 |
| GPS 异常点阈值 | 数据清洗用的，不是业务规则 |
| 轨迹保留天数 | 涉及个人信息保护规定，90 天是合规值 |

**要改这些之前先问技术人员。**

## 1.8 每周花 5 分钟看一次「配送分析」

左侧菜单「禹邻优鲜 → 配送分析」，选一个时间范围（比如最近 7 天）。

| 看什么 | 说明什么 | 怎么用 |
| --- | --- | --- |
| **准时率** | 有多少单在承诺时间内送到 | 低于 85% 说明承诺时间定得太紧，或者出发太晚 |
| **平均配送时长** | 从取货到送达平均多久 | 突然变长要看是不是某个片区出了问题 |
| **异常分布** | 哪种问题最多 | "顾客联系不上"多 → 下单时提醒填对电话；"地址错误"多 → 地址库该整理了 |
| **楼栋难度榜** | 哪栋楼最费时间 | 排在前面的楼，以后可以主动跟顾客约"放门口"，或者调整送货顺序 |

# 第二部分 · 送货人篇

> 这一部分给拿着手机送货的人看。APP 名字叫「**禹邻优鲜骑手**」，图标在手机桌面上。

## 2.1 第一次用，要做四件事（大约 20 分钟，只做一次）

### ① 登录

1. 打开 APP
2. 输入**手机号**（店长给你建账号时用的那个）
3. 输入**初始密码**（店长给你的）
4. 点「登 录」

登不进去 → 看 2.9 节。

### ② 改密码

第一次登录，系统**强制**要求改密码。改一个自己记得住的，别用 123456。

改完之后初始密码就作废了。

### ③ 三步授权

改完密码会自动进入授权引导页，一共三步，**三步都做完才能上班接单**。

| 步骤 | 要开什么 | 为什么 | 不开会怎样 |
| --- | --- | --- | --- |
| **第 1 步** | 定位权限 + 通知权限 | 定位用来派顺路的单、算送达时间；通知用来在有新单时叫醒你 | 收不到单，也上不了班 |
| **第 2 步** | 位置信息授权同意 | 法律要求对精确位置单独征得你同意，所以单独一屏 | 上不了班 |
| **第 3 步** | 后台定位选「**始终允许**」 | 送货时你会锁屏、会接电话、会开导航。只有选"始终允许"，锁屏后位置才不会断 | 一锁屏位置就停，店长会看到你"掉线" |

⚠️ **第 3 步最容易出错。**安卓 11 以后，系统不会直接弹出"始终允许"这个选项，你得：
1. 先选「仅在使用该应用时允许」
2. 回到 APP 点一下这一步的按钮
3. 系统会跳到设置页，在「位置信息」里手动选「始终允许」

如果哪一步的弹窗被手机拦掉了没出现，点旁边的「**打不开？去应用设置**」，直接进系统设置页手动开。

### ④ 🔴 保活向导（最重要的一步，千万别跳过）

#### 为什么必须做

国产安卓手机为了省电，会在锁屏几分钟后**把后台的 APP 冻结掉**。冻结之后：

- ❌ 位置不再上报，店长看到你"卡"在原地不动，顾客也看到骑手不动了
- ❌ **新订单收不到**，手机不响，你在店里干等着不知道有单来了
- ❌ 你以为 APP 在跑，其实它早就被系统杀了

**这不是 APP 的 bug，是所有国产安卓手机的通病。**外卖平台的 APP 也要做同样的设置，只是他们有专人上门帮骑手设置。

#### 怎么做

1. APP 底部点「**我的**」
2. 点「**设置**」
3. 点「**保活向导**」
4. 里面分三大步、十几个小项，**每一项都点进去，跳到系统设置里真的改一次，回来看到状态变成"已完成"**

APP 会自动识别你的手机品牌，显示对应的设置路径。支持这些品牌：

小米 / 红米、华为、荣耀、OPPO / realme、vivo / iQOO、三星、魅族、努比亚、中兴、传音（TECNO / Infinix）、联想 / 摩托罗拉，其他品牌走通用方案。

#### 三大步分别是什么

| 步骤 | 内容 | 说明 |
| --- | --- | --- |
| **第一步 · 系统权限** | 精确定位、后台定位"始终允许"、通知权限、电池优化白名单 | 这四项 APP 能自动检测，做完会自动打勾 |
| **第二步 · 品牌专项** | 自启动、省电策略改成"无限制"、后台弹出界面…… | 各品牌不一样，按屏幕上写的做 |
| **第三步 · 使用习惯** | 在"最近任务"里给 APP 加锁、送货时别开省电模式、保持系统定位总开关打开 | 这些是日常习惯，要记住 |

#### 几个最容易漏的

| 品牌 | 最关键的那一项 |
| --- | --- |
| 华为 / 荣耀 | 「手机管家 → 应用启动管理」里，**关掉"自动管理"**，然后把"允许自启动""允许关联启动""允许后台活动"**三项全部打开** |
| 小米 / 红米 | 「省电策略」改成「**无限制**」（默认是"智能省电"，会杀后台） |
| OPPO / vivo | 在**最近任务界面下拉 APP 卡片，点小锁图标锁住**，否则一键清理会把它清掉 |
| 三星 | 「永不休眠的应用」里加上本 APP，并关掉「自适应电池」 |
| 所有品牌 | **送货期间不要开省电模式。**电量低于 20% 时手机可能自动开启，注意充电 |

#### 做完怎么验证

做完之后测试一下：
1. 点「上班」
2. 手机锁屏放兜里，**过 30 分钟**
3. 让店长在后台看你的位置有没有在动

位置一直不动 → 保活没做好，回去重做一遍。

## 2.2 每天上班怎么操作

### 到店之后

1. 打开 APP，首页最上面有一个**上班/下班开关**
2. 点「**上班**」

点完之后会发生什么：
- 定位开始上报（手机通知栏会出现一条常驻通知，**不要划掉它**）
- 系统开始给你派单
- APP 开始每 3 秒问一次服务器有没有新单

### 🔴 不点「上班」= 收不到任何单

这是最常见的"APP 没反应"的原因。系统只给"在岗"的人派单。

### 收工之后

点「**下班**」。

**为什么一定要点下班**：
- 定位会一直跑，很耗电
- 你的位置会一直被记录，没必要
- 店长后台会一直显示你在岗，看着以为你还在送

APP 里那句话说得很清楚："收工请记得点下班，否则定位会一直运行耗电。"

### 班次页能看到什么

首页往下拉，或者「我的 → 今日统计」：

在线时长 / 今日单量 / 已完成 / 准时送达 / 配送里程

## 2.3 收到新单怎么接

### 有新单时手机会怎么提醒你

1. 手机**响铃**（会重复播报几次，直到你确认）
2. **语音播报**，说的是："您有 1 个新订单，XX 小区，2.1 公里"
3. 通知栏出现一条通知，点它直接进任务详情

### 接单步骤

1. APP 首页「**待接单**」区域会出现新的卡片
2. 点开看：地址、几件东西、多重、承诺几点送到、顾客备注
3. **手指按住滑块，从左滑到右**，完成接单

> **为什么是滑动不是点击？**戴着手套、手上拿着东西的时候，点击很容易点错。滑动需要一个完整的动作，误触概率极低。而且送达那一步滑错了后果很严重（订单直接变已完成）。
>
> 另外，刚打开页面的**头 0.8 秒滑块是划不动的**，这是防止你在列表页滑动的惯性直接把送达划掉。

## 2.4 取货核对

接单之后，如果这一趟有好几单，APP 会让你做一次取货核对。

1. 任务详情页滑动「**滑动去取货核对**」
2. 进入核对页，最上面显示「**本趟共 N 单**」「X 件 · Y 袋」
3. 有冷冻商品时会有醒目提示：「🧊 含冷链商品，先装保温箱」
4. 下面是这一趟每一单的列表，**一单一单打勾**（全对的话可以点右上角「全选」）
5. 全部勾完，提交

**核对完之后**：
- 订单状态自动变成「配送中」
- 顾客在小程序上开始能看到你的位置

### 核对时对不上怎么办

| 情况 | 怎么办 |
| --- | --- |
| 少了一袋 | 先找找，找不到就问店长。别硬着头皮走 |
| 多了一袋 | 看是不是别的单的，问店长 |
| 袋子破了 | 直接上报异常，选「商品破损」，拍照 |

## 2.5 送达要怎么确认（必须拍照）

1. 到了地方，在任务详情页滑动「**滑动去送达（需拍照）**」
2. 进入送达页
3. 点「**拍照**」，拍一张能说明送到了的照片

### 照片拍什么

屏幕上有提示：「拍摄送达凭证：请拍到**门牌**或**货品**」

| 交付方式 | 建议拍什么 |
| --- | --- |
| 当面交给顾客 | 拍手里的袋子 + 门牌号 |
| 放门口 | **必须拍**：东西放在门口 + 门牌号在同一张照片里 |
| 放前台 / 快递柜 | 拍东西放好的位置 + 能看出是哪的标志 |

照片会自动加上**时间和地点水印**，改不了。以后顾客说"没收到"，这张照片就是证据。

4. 选交付方式（当面 / 放门口）。顾客备注里写了"放门口"的话，系统会自动帮你选好
5. **拍完照之后滑块才能滑动**，没拍照是划不动的
6. 滑动确认

### 送达之后自动发生的事

- 订单状态变成「已完成」
- 顾客小程序上进度条走到最后一格
- 顾客可以给这次配送打分了

## 2.6 遇到问题怎么上报

### 什么时候要上报

只要**不能正常送达**，就上报。上报之后：
- 店长后台立刻能看到，会帮你处理
- 有照片有记录，以后不会说不清
- 系统会自动免除你的责任

**别自己扛着，也别只是打个电话说一声。**电话说的没记录。

### 怎么上报

1. 任务详情页点「**⚠️ 上报异常**」
2. 屏幕上有 13 个方块，选一个最接近的：

| | | |
| --- | --- | --- |
| 📵 顾客联系不上 | 🗺️ 地址错误 | 🙅 顾客拒收 |
| 📦 商品破损 | 💧 商品漏液 | ⚖️ 缺斤少两争议 |
| 🔍 缺件少件 | 🚪 门禁进不去 | 🛵 车辆故障 |
| 🤒 身体不适 | 🌧️ 天气恶劣 | 🏪 门店出货慢 |
| ❓ 其他 | | |

3. **拍照**（有几种类型是必拍的，屏幕上会写"(必拍)"）
4. 打字说明一下情况
5. 提交

### 提交之后 APP 会告诉你接下来怎么做

比如选了「顾客联系不上」，APP 会显示：

> 电话与短信各联系两次并间隔等待，仍无应答再拍照留证上报调度

按提示做，然后等店长处理。店长处理完，你的 APP 上会收到消息。

### 三种最常见情况的标准动作

| 情况 | 标准动作 |
| --- | --- |
| **顾客联系不上** | ① 打电话，没接 ② 隔 3～5 分钟再打一次 ③ 发条短信 ④ 还是没反应就上报，拍一张门口的照片 ⑤ 等店长处理，**期间可以先送这一趟的其他单** |
| **地址错** | ① 先打电话问清楚 ② 在附近（几百米内）就直接送过去 ③ 差得远就上报，等店长决定 |
| **东西坏了 / 漏了** | ① **立刻拍照**（这是关键，事后补拍没用） ② 漏液的话把它跟别的单隔开，别污染了 ③ 上报，选「商品破损」或「商品漏液」 ④ 跟顾客说一声，别硬送 |

## 2.7 没有网络的时候能不能用

**能用。这是专门做过的。**

### 没网的时候会怎样

你在 APP 上做的所有操作 —— 接单、取货核对、送达、拍照、上报异常 —— 都会**先存在手机里**，一有网就自动传上去。

- 位置也一样：没网的时候位置点存在手机里，有网了一批一批补传
- 你按下按钮的**真实时间**会一起记下来，不是按补传的时间算，所以不会因为没网就被算成超时
- 照片也会先压缩存在手机里，联网后自动上传

### 你需要做什么

**什么都不用做，正常操作就行。**

APP 上会显示还有几条没传上去。走到有信号的地方，等几秒就自动清零了。

### 需要注意的

| 注意 | 说明 |
| --- | --- |
| 别在没网的时候卸载 APP | 没传上去的操作会丢 |
| 长时间没网（比如一整天） | 尽量走到有信号的地方传一次，别攒太多 |
| 没网时地图是刷不出来的 | 位置和操作都正常记录，就是地图底图看不见 |
| 如果 APP 提示"同步异常" | 点一下手动重试。还不行告诉店长 |

## 2.8 手机使用的几个注意事项

| 事项 | 为什么 |
| --- | --- |
| 🔋 **带充电宝** | 持续定位比较耗电，一上午能掉 30%～50% |
| 🚫 **不要开省电模式** | 任何品牌的省电模式都会限制后台定位。电量低于 20% 时手机会自动开，注意充电 |
| 🚫 **不要清后台** | 别习惯性地把后台全清掉。要清也先在"最近任务"里给本 APP 加锁 |
| 🚫 **不要划掉通知栏那条常驻通知** | 那条通知就是定位服务在跑的标志，划掉了定位就停了 |
| ✅ **保持系统定位总开关打开** | 下拉通知栏能看到"位置"图标，确保是亮的 |
| 📵 **上下班要点** | 上班才派单，下班才停止定位省电 |

## 2.9 登不进去 / 收不到单，先自查这几条

| 现象 | 先检查 |
| --- | --- |

# 第三部分 · 顾客能看到什么

> 顾客打电话问的时候，照着这一节回答。

## 3.1 顾客在小程序上能看到什么

顾客打开小程序 →「我的订单」→ 点开那一单 → 订单详情页。

**只有在"配送中"这个阶段，才会显示配送信息。**下单后还没打包、以及送达之后，看到的都是普通的订单页。

| 顾客能看到 | 说明 |
| --- | --- |
| **实时地图** | 送货人的图标在地图上移动，还能看到目的地。图标是**平滑移动**的，不是一跳一跳的 |
| **预计送达时间** | 显示一个区间，比如"预计 14:20-14:30 送达"。给区间不给精确时间，是因为路上总有变数，区间更容易做到 |
| **还剩多久** | 比如"约 12 分钟后送达" |
| **还有几单** | 比如"骑手还有 2 单送达你"或"你是骑手的下一单" |
| **五步进度条** | 已安排骑手 → 骑手已取货 → 配送中 → 即将送达 → 已送达，每一步带时间 |
| **送货人信息** | 姓名、头像、评分、"电动车配送" |
| **联系骑手按钮** | 点了直接拨号 |
| **地图折叠** | 可以「收起地图」，省流量 |
| **送达后评价** | 1～5 星 + 标签（准时/礼貌/包装完好/态度好）+ 一句话评论 |

## 3.2 顾客问的常见问题，怎么回答

| 顾客问 | 你答 |
| --- | --- |
| "怎么看不到骑手在哪？" | 要等东西打包好、骑手取货之后才会显示地图。刚下单看不到是正常的 |
| "地图上骑手不动啊？" | 可能是骑手手机信号弱。稍等一下会跳过来。**如果超过几分钟还不动，你去后台看看是不是"定位陈旧"标红了** |
| "为什么写的是一个时间段不是准点？" | 路上会有红绿灯、进小区找楼的时间，给个区间更实在，也不会让你白等 |
| "我想改成放门口" | 让顾客在订单备注里写"放门口"，送货人 APP 上会看到并自动选择"放门口"这种交付方式 |
| "送到了怎么没通知我？" | 目前微信不会主动推送提醒，需要顾客自己打开小程序看。（想要微信提醒的话需要另外配置，见《交付说明》第四节） |
| "我要投诉/评价" | 订单送达后小程序上会出现"去评价"按钮 |

## 3.3 顾客隐私相关

| 项 | 现在的设定 |
| --- | --- |
| 顾客能看到送货人的实时位置吗 | ✅ 能，但**只能看到当前位置，看不到走过的路线**；订单一结束，位置接口立刻失效 |
| 送货人能看到顾客的真实手机号吗 | ✅ 能（你确认过不需要隐藏） |
| 位置记录保存多久 | 90 天，之后系统自动删除 |
| 下班之后还记录位置吗 | ❌ 不记录。点了"下班"是真的停止采集，不是隐藏 |
